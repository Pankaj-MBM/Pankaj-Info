## Overview

A multi-page website for a CCTV and security-services business. Visitors browse services — CCTV installation and maintenance, IP cameras, smart-home, office and industrial surveillance, remote monitoring — see past projects and pricing, and request a quote or call in one tap.

## Features

- **Service and project pages** with dedicated detail routes.
- **Pricing** and **contact** pages plus a **get-started quote form**.
- **CCTV preview videos** to show real camera coverage.
- **Floating call & WhatsApp buttons** for instant enquiries on mobile.

## Build & delivery

Built with an **AI-assisted workflow** (Lovable) in **React + TypeScript** with **Tailwind CSS** and **shadcn/ui**. A **Jenkins** pipeline deploys the build output to an **Nginx** web root on a Linux server — sync, permissions and an Nginx reload in one run.
